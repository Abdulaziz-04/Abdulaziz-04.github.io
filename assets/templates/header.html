Fan-out/fan-in pipeline using CompletableFuture to keep API hops non-blocking. 

// Merge multiple upstream calls without thread explosion
CompletableFuture<User> user = userClient.fetchAsync(userId);
CompletableFuture<List<Order>> orders = orderClient.fetchAsync(userId);

// Compose downstream step once both complete
return user.thenCombineAsync(orders, (u, o) -> assembleProfile(u, o))
           .orTimeout(2, TimeUnit.SECONDS)   // fail fast for SLOs
           .exceptionally(this::fallbackProfile);
Python

Structured retry with jitter and contextual logging wrapper for flaky I/O. 

import random, time, logging

def with_retry(fn, attempts=3, base=0.15):
    for attempt in range(1, attempts + 1):
        try:
            return fn()
        except Exception as exc:
            jitter = base * (1 + random.random())
            logging.warning("retry %s/%s after %.2fs: %s", attempt, attempts, jitter, exc)
            time.sleep(jitter)
    raise RuntimeError("exhausted retries")
JavaScript (Node.js)

Stream pipeline that backpressures while transforming large JSON logs. 

import { createReadStream, createWriteStream } from "fs";
import { pipeline } from "stream/promises";
import split2 from "split2";

// Backpressure-aware transform
const redact = async function* (lines) {
  for await (const line of lines) {
    const entry = JSON.parse(line);
    entry.email = "[redacted]"; // scrub PII
    yield JSON.stringify(entry) + "\\n";
  }
};

await pipeline(
  createReadStream("raw.log"),
  split2(),          // turn file into lines
  redact,            // async generator preserves pressure
  createWriteStream("clean.log")
);
C#

Policy-based resilience wrapper with typed pattern matching on results. 

public async Task<Result> FetchWithResilience(Func<Task<Result>> work)
{
    for (var attempt = 1; attempt <= 3; attempt++)
    {
        var result = await work();
        switch (result)
        {
            case Success s: return s;
            case TransientError e when attempt < 3:
                await Task.Delay(TimeSpan.FromMilliseconds(200 * attempt));
                continue; // retry with backoff
            default: return result; // bubble permanent errors
        }
    }
    return new Failure("Retries exhausted");
}
