connected clients.

### Tiltastic - Home Décor Tile Visualizer
Tiltastic - Home Décor Tile Visualizer
A computer vision powered web application that lets users upload a
room photo, pick a tile design and instantly preview how different
floors or walls would look, using monocular depth estimation and
floor segmentation behind a simple interface.

### Tech Stack
Tech Stack:
React, Flask, Tensorflow, Keras, OpenCV, AWS
Learn more!

### Accessible Drum Machine for the Visually Impaired

A keyboard driven, screen reader friendly drum machine built in

operated with the keyboard and ARIA announcements.

### Tech Stack
Tech Stack:
React 18, CRA, CSS, ARIA attributes
Learn more!
