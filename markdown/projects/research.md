# Published research projects: VR Humanoid Agents & statistical modeling
Published research projects: VR Humanoid Agents & statistical modeling

### LLM-driven Humanoid Agents in Social Virtual Reality
LLM-driven Humanoid Agents in Social Virtual Reality
Research apprenticeship project that built memory-aware agents in
VRChat using GPT-4. The NPCs remember prior conversations, pass
information between players, and respond with appropriate
dialogue, facial expressions, and body gestures in real time.

### Tech Stack
Tech Stack:
OpenAI API, GPT-4, VRChat, Python,
MongoDB, Unity, Whisper API, Vosk, OCR, Custom RAG pipeline
Learn more!

### Statistical Analysis of TA Hiring Bias in Computing Programs
Statistical Analysis of TA Hiring Bias in Computing Programs
Data-driven intersectional study that analyzed more than 15,000
teaching assistant applications across computing courses to
uncover gender and demographic disparities in TA hiring and to
inform equity focused policy changes.

### Tech Stack
Tech Stack:
Python, pandas, NumPy, SciPy, statsmodels, matplotlib, Plotly,
Jupyter
